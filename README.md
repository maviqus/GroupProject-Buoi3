## Development Workflow
1. Create feature branch from develop
2. Implement features with proper commits
3. Create Pull Request to develop
4. Require at least 1 review approval
5. Team lead merges after review

## Branch Structure
- `develop` - Main development branch
- `feature-[Name]` - Feature branches for each member
- `test-[Name]` - Testing branches for experiments
